# A/B观察邮件与策略累计收益

保留旧规则提醒。A/B是旧规则合格信号上的观察标签；同时命中时只保存和发送一条信号，显示A+B，不另外发送候选邮件。未命中的旧提醒继续发送。

- A：SELL、闭合小时收盘价低于SMA50、成交量至少为20期均量的1.3倍。
- B：A加上唐奇安突破参与、触发收盘实际跌破原下轨，发送前公开报价在原下轨下方0至0.5个触发ATR内。缺少报价时不标B。
- 候选标为观察层，保留原策略名、参与策略、触发收盘时间、报价获取时间和原止盈止损。

## 邮件收益口径

上线后的每条已送达信号建立独立100 USDT名义参考，起点为报价取得与SMTP送达两者较晚时刻之后的下一完整分钟开盘。A或旧规则的可选报价缺失时，以SMTP送达后的下一完整分钟开盘建立参考，不回用触发价。B始终需要报价才能被标注。

使用固定原止盈止损和连续1分钟行情先触及结果；跳空按可见开盘处理，同时触及保守按止损；不使用自动下单、移动止损或新增失效退出。双边手续费和滑点0.14%，再计持有期间的公开历史资金费。资金费毫秒抖动归入所在分钟；同分钟新建参考不收该笔资金费。

累计净收益按“规则组（OLD/A/B）+最终原策略”分别汇总，只加已结束参考。A+B复用一条记录，组间不可相加。未结束、待复盘、正常无效参考分别计数；没有已结束样本时显示暂无样本，数据不完整时不伪装为0。旧规则在本次上线前的legacy记录不混入新统计。这些金额不是用户人工账户损益，也不模拟多信号组合资金约束。

2026-09-08至10-31的A/B历史研究结果作为固定快照单列，初始10,000 USDT、18币分配，与上线观察的100 USDT逐条参考口径不同，不相加、不滚动伪装为在线收益。

## 持久化与运行

复用crypto_signals.raw_features.observation JSON字段存规则版本、分组、时间和增量复盘状态，无新增数据库表或列。只有确认送达的记录进入复盘。保存增量游标时比较旧游标，避免并行刷新覆盖新进度。

每次原有分档检查先刷新历史观察，再检查新信号。刷新最多4条、设时间预算并按最早复核时间轮转，避免慢行情阻断新提醒。每条最多回放1,500分钟；缺口不跳过，后续可续算，未追平会标统计不完整。

此次沿用原Vercel日频分档调度：UTC 00/01/02时，即北京时间08/09/10时，由平台实际触发；没有改成此前研究的小时检测频率。WebSocket入口也接入同一观察分层与邮件格式。
